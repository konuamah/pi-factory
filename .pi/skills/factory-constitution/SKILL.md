# Factory Constitution

Use this when the user asks about repository memory, `CONSTITUTION.md`, constitution refresh, or missing constitution readiness.

`CONSTITUTION.md` is the repository truth file for how the project is built, organized, tested, secured, deployed, and maintained. It is part of Factory readiness.

Use `/factory constitution` for generation or refresh. Setup may write a stub first and then run the constitution flow when generation or refresh is selected.

Do not manually author detailed constitution prose unless the user explicitly asks for a manual edit. Prefer the constitution scan/generation path.
